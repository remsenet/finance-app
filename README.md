# 💰 종합 재정관리 플랫폼 (My Finance Platform)

개인 자산을 한눈에 파악하고, 세후 수익률 계산부터 고금리 예금 추천, 목표 자산 시뮬레이션까지 지원하는 올인원 재정관리 웹 애플리케이션입니다[cite: 1].

## ✨ 주요 기능 (Key Features)
- **통합 대시보드**: 총 매입금액, 총 평가금액, 총 평가 손익, 포트폴리오 수익률 요약 및 이미지 공유 기능[cite: 1]
- **자산별 성과 분석**: 주식, 예금, 부동산 자산의 평가금액 vs 시장가격 비교 차트 및 상세 Layer Popup 제공[cite: 1]
- **스마트 알람 & 세금 토글**: 예금 만기 3일 전/1일 전 사전 알림 센터 및 양도세/이자소득세 즉시 반영 스위치[cite: 1]
- **고금리 은행 추천**: 시중은행 및 저축은행의 최고금리 정기예금/파킹통장 실시간 비교 추천[cite: 1]
- **상세 관리 도구**: 거래 상세 원장, 금융 캘린더, 포트폴리오 리밸런싱 진단, 복리 기반 목표 달성 시뮬레이터, 엑셀 내보내기 및 다크 모드 지원[cite: 1]
